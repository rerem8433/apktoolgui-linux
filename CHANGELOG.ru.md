# Список изменений

[English](CHANGELOG.md) | [Français](CHANGELOG.fr.md) | [Español](CHANGELOG.es.md) | **Русский**

Здесь перечислены все значимые изменения **APK Tool GUI Linux**.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.0.2] - 2026-11-21

### Добавлено
- Интерфейс на **испанском** и **русском** в дополнение к английскому и французскому (выбор в *Настройки → Язык*, по умолчанию язык системы).
- Действия контекстного меню Nemo и ярлык в меню переведены на все 4 языка.
- Стандартные кнопки (ОК/Отмена, Да/Нет) переведены; стандартные диалоги Qt переводятся, если установлен пакет `qt6-translations-l10n` (рекомендуется пакетом .deb).
- Окно «О программе» переведено и показывает версию встроенного Apktool.
- README и CHANGELOG доступны на английском, французском, испанском и русском.

### Изменено
- **Apktool 3.0.2 → 3.0.3**: исправлены ошибки «android:* not found», допускаются пустые значения флагов, оптимизирован пул строк. Параметры командной строки не изменились.
- **APKEditor 1.4.7 → 1.4.9**: исправлена ошибка слияния split APK, обработка «wide»-регистров в smali, повышена производительность.
- Окно при необходимости расширяется, чтобы все 9 вкладок оставались видимыми (русский язык).
- Сборка GitHub Actions: `actions/checkout` и `actions/upload-artifact` обновлены до v7 (Node.js 24), предупреждение об устаревании Node.js 20 больше не выводится.

### Исправлено
- Строка «Picked up _JAVA_OPTIONS…» отображалась вместо версии APKEditor, если задана переменная `_JAVA_OPTIONS` (часто используется в Linux для сглаживания шрифтов Java). Теперь такие строки отфильтровываются везде.
- Обрезанные кнопки действий при длинном тексте (вкладка Baksmali на русском).

## [1.0.1] - 2026-10-28

### Исправлено
- **Отсутствующий значок на вкладке «Инфо APK»** у современных приложений (например, AnyDesk), использующих адаптивный XML-значок (`mipmap-anydpi-v26`) с сокращёнными или обфусцированными именами ресурсов.

### Добавлено
- Новый механизм извлечения значков (`icon.py`) на основе ID ресурсов (`aapt2 dump resources` / `dump xmltree`):
  - находит оригинальный PNG/WebP наибольшей плотности за адаптивным значком;
  - иначе отрисовывает адаптивный значок: фон, передний план, VectorDrawable (группы, трансформации, clip-path), `inset`, `layer-list`, `bitmap`, `shape`, линейные/радиальные градиенты, маска со скруглёнными углами;
  - в крайнем случае использует значок, указанный в AndroidManifest;
  - работает и при обфусцированных именах атрибутов и ресурсов (R8, AndResGuard, `--shorten-resource-paths`).
- Резервное преобразование WebP → PNG через Pillow, если плагин WebP для Qt отсутствует.

### Изменено
- Новые зависимости пакета: `python3-pyqt6.qtsvg`, `qt6-image-formats-plugins`.

## 1.0.0 - 2026-10-19

*Не публиковалась на GitHub (репозиторий создан с версией 1.0.1).*

Первая версия: нативный порт для Linux (Python 3 + PyQt6) программы [APKToolGUI](https://github.com/AndnixSH/APKToolGUI) 3.4.0.0 от AndnixSH.

### Добавлено
- 9 вкладок оригинала: Главная, Инфо APK, Декодирование, Сборка, Подпись, Выравнивание, Фреймворк, Baksmali, ADB.
- Встроенные инструменты: Apktool 3.0.2, APKEditor 1.4.7, apksigner, smali/baksmali, aapt2 для Linux.
- Декомпиляция/сборка через Apktool или APKEditor (проекты APKEditor определяются автоматически).
- Слияние XAPK/APKS/APKM/ZIP и прямая декомпиляция split APK.
- Цепочка сборка → zipalign → подпись → установка через ADB; неподписанный APK с оригинальной подписью.
- Автоматическое исправление ошибок Apktool (manifest, `sparseResources`, `APKTOOL_DUMMY`).
- Подпись ключом pem/pk8 или keystore JKS, схемы v1–v4; пароли передаются через переменные окружения.
- Параметры, адаптированные под Apktool 3 (`-a`, `--no-assets`, `--only-manifest`, `--debuggable`, тег фреймворка).
- Вкладка ADB: список устройств, подключение по Wi-Fi `IP:порт`, установка (`-i com.android.vending`, `--abi`).
- Действия контекстного меню Nemo (Linux Mint), установленные для всей системы.
- Командная строка: `--decompile`, `--compile`, `--sign`, `--align`, `--merge`, `--info`, `--baksmali`, `--install`.
- Необязательная загрузка официальных platform-tools / build-tools от Google из Настроек.
- Интерфейс на английском и французском, тёмная/светлая тема, drag & drop везде, цветной журнал.
