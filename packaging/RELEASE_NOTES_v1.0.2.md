## APK Tool GUI Linux 1.0.2

Native Linux port (Python 3 + PyQt6) of [APKToolGUI](https://github.com/AndnixSH/APKToolGUI) 3.4.0.0, by ParadoxXx Squad.

### What's new
- **Spanish** and **Russian** interface (in addition to English and French): app, Nemo right-click menu, menu shortcut.
- **Apktool 3.0.3** (fixes "android:* not found" errors) and **APKEditor 1.4.9** (fixes split APK merging).
- README and CHANGELOG in 4 languages.

### Fixes
- APKEditor version hidden by the "Picked up _JAVA_OPTIONS" line when that variable is set.
- Hidden tabs and cut-off buttons in Russian.

### Installation (Linux Mint 21/22, Ubuntu 22.04+)
```
sudo apt install ./apktoolgui-linux_1.0.2_amd64.deb
```
