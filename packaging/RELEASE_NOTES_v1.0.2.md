## APK Tool GUI Linux 1.0.2

Portage Linux natif (Python 3 + PyQt6) d'[APKToolGUI](https://github.com/AndnixSH/APKToolGUI) 3.4.0.0, par ParadoxXx Squad.

### Nouveautés
- Interface en **espagnol** et en **russe** (en plus du français et de l'anglais) : appli, clic droit Nemo, raccourci du menu.
- **Apktool 3.0.3** (corrige les erreurs « android:* not found ») et **APKEditor 1.4.9** (corrige la fusion des split APK).

### Corrections
- Version d'APKEditor masquée par la ligne « Picked up _JAVA_OPTIONS » quand cette variable est définie.
- Onglets cachés et boutons tronqués en russe.

### Installation (Linux Mint 21/22, Ubuntu 22.04+)
```
sudo apt install ./apktoolgui-linux_1.0.2_amd64.deb
```
